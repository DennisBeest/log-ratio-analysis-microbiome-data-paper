
# results and code

Here you can find the data for the two examples (.RData files), and a file with functions that are used across the various analyses/figures. Both examples include a matrix with count data (samples x taxa), and vector with a dichotome treatment.

The folders each contain one of more analyses/figures:
- CombinedPics: supplement figures and code
- barplotType1Power: figures 5 and 6 of the paper  
- extraExamples: extra examples from the supplement  
- mainFigs: figures 2 and 3 of the paper  
- picCorGamma: figure 18 of the supplement  
- powerType1: results and code of the type1 and power simulations, and fig 4 of the paper
- rowmeans: fig 1 of the paper
