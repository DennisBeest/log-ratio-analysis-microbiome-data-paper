
# Log-ratio analysis of microbiome data

This is code belonging to the paper:  
https://onlinelibrary.wiley.com/doi/full/10.1111/1755-0998.13391

This paper also has long supplement:  
https://onlinelibrary.wiley.com/action/downloadSupplement?doi=10.1111%2F1755-0998.13391&file=men13391-sup-0001-Supinfo.pdf

The paper is about applying LRA (log-ratio analysis) to microbiome data; and how this may not work well under certain conditions.

For more info on LRA see for example: https://rdrr.io/cran/easyCODA/man/LRA.html and the various papers by  Michael Greenacre on the topic.
